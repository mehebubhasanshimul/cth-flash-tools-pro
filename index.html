CONNECTION GUIDE

USB / OTG

ডেটা-সাপোর্টেড OTG কেবল/অ্যাডাপ্টার ব্যবহার করো। Android host permissions ও browser support ডিভাইসভেদে আলাদা।

ADB

নিজের Android ফোনে Developer options থেকে USB debugging চালু করো। বিশ্বস্ত কম্পিউটারের RSA prompt ফোনে নিজে যাচাই করে অনুমোদন দাও।

FASTBOOT

শুধু নিজের ডিভাইসের প্রস্তুতকারকের অফিসিয়াল নির্দেশনা অনুসরণ করো। Flash/erase/unlock-এর আগে সম্পূর্ণ মডেল ও firmware নিশ্চিত করা জরুরি।

APP MODE

WebIntoApp wrapper একা native USB/ADB permission তৈরি করে না। এর জন্য আলাদা native Android plugin/bridge ও তার অনুমোদিত implementation প্রয়োজন।
